TigerSteps Product Return Request

Submit one online footwear return request for a previous TigerSteps purchase.

Before You Submit

Have your Customer ID and Order ID ready. Select Find My Order to view the footwear purchased, original quantity, and delivery date.

MIS 3371 client-side demonstration: order information comes from fictional purchase records. An eligibility result is a preview only; no Return ID is issued, no official request is saved, and no refund is processed.

Return Request Details

Customer Information

If provided, use the format 713-555-0123.

Order Information

Enter Customer ID and Order ID, then choose Find My Order. Both values must match a fictional purchase record.

Purchased quantity and delivery date will be populated automatically from the fictional record for your selected item. They cannot be edited.

Return Details

This checkbox does not upload a file and is not a standalone eligibility requirement.
